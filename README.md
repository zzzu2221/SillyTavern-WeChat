# 微信 · WeChat for SillyTavern（酒馆微信）

把 SillyTavern（酒馆）角色卡包装成一个**仿微信聊天前端**，并内置**朋友圈**与**公众号**模块。
运行在酒馆页面内（悬浮 💬 按钮打开），适配手机浏览器与桌面浏览器。

- 聊天模型 / 生图 / 通讯录白名单 / 朋友圈自动发布 / 公众号开关全部可在**设置面板**手动调节
- 数据存酒馆自己的角色卡、聊天文件与群组会话，**不需要额外后端**
- 通讯录**白名单**：只把你勾选的角色卡放进通讯录；也**只有白名单角色能发朋友圈**
- 朋友圈 / 公众号支持**分享到私信（微信式转发卡片，点击跳回原文）**

---

## 一、功能总览

### 1. 聊天（仿微信）
| 模块 | 说明 |
|---|---|
| 通讯录 | 展示**白名单内**的角色卡（头像 + 名字），点击进入最近会话；右上角 ➕「新朋友」白名单流程，同意才加入 |
| 聊天页 | 顶部角色名（点按进详情）、绿/白气泡、多气泡拆分（`\|\|\|` 分隔标记）、自动滚底、表情面板、**每角色可自定义聊天背景（含本地上传图片）**、**转发卡片**（朋友圈/公众号分享过来时显示为微信式卡片，点击跳回原文，返回回到聊天页） |
| 角色详情 | **微信个人资料风**：大头像、备注/个性签名可改、简介可折叠、历史会话可折叠、**会话可直接删除**、多开场白自动拆成独立会话 |
| 多会话 | 酒馆原生一个角色一个会话，本项目用 localStorage 自建映射，同一角色可有多条会话存档 |

### 2. 朋友圈
- 用酒馆的一个**特殊群组会话**当存储：每条动态 = 群组里一条消息，评论 = 附加消息
- 时间线滑动浏览：封面、头像、正文、**配图**（AI 生图 / 本地上传）、评论区；最新在上
- **AI 自动发圈**：选择角色后，AI 结合**与该角色的最近聊天**自动写文案 + 自动写生图提示词 + 配图并发布；配图方式可选 **无图 / AI 生图 / 上传图片**
- **我发朋友圈**：发布弹层固定以「我」的账号发布，可一键 **✨ AI 生成草稿**（AI 参考你选的角色的聊天、以玩家本人人设写文案和提示词，可改后发）
- 评论：手动评论（角色或我）或 **AI 代写评论**（以该角色身份，自动贴合朋友圈内容）；发布后可自动让关联角色来点赞评论
- **删除**：每条动态右上角 `⋯` 删除（连带评论），每条评论旁 `✕` 删除单条（自定义微信风确认弹窗）
- **分享**：每条动态可「分享」给任意白名单角色 → 以**微信式转发卡片**发进 TA 的私信（卡片带发布者与内容，AI 能正确识别"是谁发的"；**分享文案自动标注"我（玩家）分享给你看"**，AI 不会把分享者误认成朋友圈发布者）
- **单条详情页（仿微信）**：点开**转发的朋友圈卡片**直达该条动态详情——发布者大头像 / 正文 / 配图 / 评论区 / 操作栏（评论、分享、删除动态、删单条评论），返回回到来源页面（聊天页或朋友圈）
- **返回来源记忆**：从聊天页点卡片跳原文（朋友圈详情 / 公众号阅读），返回时回到原聊天页
- 朋友圈评论 / 文案的**括号动作心理描写自动清洗**（前端渲染层与 AI 生成层双重过滤，存储保留原文）；AI 偶发复读的**存储标记前缀**（`对应动态id=…;角色=…;评论=`）显示/存储前自动剥离
- **朋友圈未读小红点**：底部 Tab 朋友圈消息列显示未读角标，数字=未读消息数，按账号隔离；AI 主动发圈后自动 +1，进入朋友圈清零
- **越权防护**：只有通讯录白名单内的角色能发圈/评论；charRelations 设为「陌生人」的角色互不评论

### 3. 「我」页 + 账号管理（切号系统）
- **多 Player 账号（切号系统）**：存档在酒馆设置里，多端同步；切换账号 = 换身份，每个账号独立打包通讯录（白名单）、私信会话、群聊、朋友圈、公众号，切号后全部隔离，新账号默认空通讯录
- 每账号可设：头像（角色卡 / 酒馆用户设定 / 本地上传）、名字、微信号、**个性签名（支持 ✨ AI 生成——参考最近聊天/群聊自动生成）**、**人设描述**、朋友圈封面、**世界书/我的设定（可多选挂载多个酒馆世界书，每个世界书可像酒馆本体一样逐个勾选启用的条目，挂载状态持久化）**、**关联角色与关系**（如：五条悟=师生、备注、生图标签）
- 从酒馆「用户设定」一键导入账号（自动带上人设）
- AI 发朋友圈 / 评论 / 帮我发圈草稿 / 公众号写作时，都会带上**当前账号的人设 + 挂载的世界书 + 与角色的关系**
- **删账号连带清数据**：一键删除账号时自动清理该账号的私信会话、聊天文件、通讯录白名单、朋友圈/公众号群组，无需逐个手动删
- **角色间关系全局通用**：关系选项精简为认识/陌生人/情侣/好友/师生/同事 + 自定义词库批量管理；角色间关系挂过一次默认全局生效，不再逐角色重复设置

### 4. 公众号（底部 Tab，可开关）
- 用酒馆的另一个**特殊群组会话**当存储：每条推文 = 群组里一条消息
- 底部 Tab「📰 公众号」（设置里可整体开关），推文卡片列表 + 阅读页（正文 / 分享 / 删除）
- **AI 写推文**：只需填一个**主题/灵感**（如"新宿甜品店探店攻略"），AI 以**营销号/技术号/探店号小编口吻**生成标题 + 正文 + 拟一个**公众号名称**（发布人由 AI 拟，**不用角色名当作者，避免 OOC**）；生成后标题 / 正文 / 公众号名都可改再发布
- **普通人视角分层（通用，自适应世界观）**：探店 / 攻略 / 生活类内容默认按普通公众视角写，**不透露该世界观的隐秘设定**（超能力 / 魔法 / 灵异 / 咒力等，以你给公众号挂载的世界书为准，不写死任何具体设定词）；只有主题本身是世界观热点（如"某家族新任家主""某组织重大事件"）才以知情小编报道视角写
- **分享**：阅读页「↗ 分享到私信」→ 以**微信式转发卡片**发进角色私信（卡片带公众号名与标题，点击跳回阅读页），AI 读到公众号与内容后会展开话题讨论

### 5. 群聊（仿微信）
- 三种建群方式：手动建群、私聊里让 AI 拉群、**AI 主动拉群**（触发概率/频率可调，拉群者自动成为群主）
- **群主体系**：群主可设置/取消管理员、转让群主（可转给玩家）、踢人、禁言、改群名、发公告、清空/解散；玩家默认拥有清空/解散权限，**群成员列表「＋」可随时拉人（免权限）**
- **禁言按真实时间自动解除**，解除/被踢/改群名/发公告等操作都会在群里发系统通知，成员可围绕讨论（带操作者姓名）
- **@成员 / @所有人**：通讯录式多选 @，被提到的人必回；成员间也可互相 @
- 群回复"松弛有度"：随机条数、支持成员围绕话题自发聊多轮（不一定是回了你才聊）
- 群聊与私聊一样显示在**主聊天列表**，含未读小红点；群卡片 / 转发 / 表情与私聊一致
- **消息操作**：长按消息弹出操作菜单——AI 消息支持「撤回」（只删当前这条，AI 自然接话）、「重说」（删该条及之后所有消息，重新接话）、「删除」；玩家消息支持「删除」
- **越权防护**：AI 幻觉出群外成员时该条直接丢弃（不换人、不重写，避免人设串味）；最终防线校验发言者必须是群成员，杜绝「群里没这个人却冒出来发消息」
- **角色间关系注入**：群聊 AI prompt 自动注入【成员间关系】（charRelations 全局通用），成员互动时称呼、亲疏、态度符合关系设定

### 6. 设置面板（悬浮按钮 → ⚙️）
- **在酒馆「扩展程序」设置页也能开关**：酒馆设置 → 扩展程序，能看到「微信 · WeChat for SillyTavern」抽屉，含 **启用扩展** 和 **显示悬浮窗按钮** 两个开关
- **通讯录白名单**：全选 / 清空 / 反选；同名角色卡可分别勾选；支持「按酒馆 tag 自动加入通讯录」（如建一个 tag `朋友`，打上该 tag 的角色卡自动进通讯录）
- **聊天模型**：来源 / API 地址 / 模型 / 温度 / 最大 Token（**留空 = 用酒馆当前配置**）
- **生图（对齐智绘机）**：直连 NovelAI API（与智绘机同机制）、**一键从智绘机导入全部配置与预设**（模型/宽高/步数/采样器/调度器/API Key/**正负面提示词/质量标签 AQT/全部提示词预设**）；AI 发圈自动带上角色生图标签 + 质量标签，出图效果与智绘机一致
- **朋友圈**：AI 一键发圈是否直接发布、自动评论开关与数量（支持**最少～最多随机区间**）
- **公众号**：底部 Tab 的开关（默认开）
- **群聊 / AI 主动行为**：AI 主动拉群、主动发消息、群内自发聊天、@必回是否必回等的**开关 + 频率 + 概率 + 时段**，都可手动调节（私聊/群聊分开）

### 7. 数据备份 · 账号整体迁移（一键搬号）
- 「我」页 → **📦 数据备份**：把**当前账号**整体打包成一个 JSON 备份文件
  - 该账号通讯录连接的**角色卡**（完整 png，含人设数据）
  - 该账号勾选的**世界书**（整本）
  - 该账号的**聊天记录**（逐会话私聊 + 朋友圈/公众号群聊消息）
  - 账号设置（关系 / 备注 / 白名单 / 会话映射 / 朋友圈·公众号群组 ID / 各开关）
- **换电脑**：新机装好微信插件 → 导入备份 → 角色卡自动写回酒馆、世界书自动挂上、聊天记录（含朋友圈/公众号）还原、通讯录白名单自动修复 key、账号配置全部回来，无需重新挂卡 / 勾选 / 设关系
- **API 安全**：生图 / 聊天 **API Key 不导出**（备份里不含，避免外泄）；导入时保留本机 Key，不会覆盖
- **多账号安全**：导入时 players 合并——同 id 账号覆盖、其他账号保留，不丢本机已有账号

## 二、安装（在你的酒馆上装一次）

### 方式 A：酒馆扩展管理器（推荐，可自动更新）
1. 打开酒馆 → 右侧「扩展」菜单（拼图/扳手图标）
2. 切到「第三方扩展」→ 「安装扩展」，粘贴仓库地址：
   ```
   https://github.com/zzzu2221/SillyTavern-WeChat
   ```
3. 安装后启用 **「微信 · WeChat for SillyTavern」** 扩展。
4. 刷新酒馆页面，屏幕中央会出现绿色 **💬** 悬浮按钮（可长按拖到任意位置）。

### 方式 B：手动拷贝
把本仓库的 `manifest.json` + `extension/` + `app/` 整体复制到酒馆的
`SillyTavern\data\default-user\extensions\SillyTavern-WeChat\`（或全局
`public\scripts\extensions\third-party\SillyTavern-WeChat\`）下，然后在扩展列表里启用。

## 三、使用步骤

1. 点悬浮 **💬** 打开微信
2. 首次进入会自动创建「朋友圈」和「公众号」两个群组（酒馆里名为 `朋友圈` / `公众号`）
3. 「我」页 → 账号管理：确认/导入你的账号（人设/多选挂载世界书/关联关系）
4. ⚙️ 打开设置：勾选要放进通讯录的角色卡，点保存
5. 通讯录选角色 → 开始聊天；朋友圈页右上角 📷 手动发布 / 🤖 AI 自动发圈；底部 Tab「📰 公众号」AI 写推文

### 生图（NovelAI）配置
- **推荐**：设置面板 → 生图 →「↺ 从智绘机导入」一键带入智绘机全部参数与预设（若装了智绘机 st-chatu8）
- 未装智绘机：手填 API Key（酒馆密钥 `api_key_novel` 也可）、模型 `nai-diffusion-4-5-full`、尺寸、采样器等
- AI 发圈 / 手动生图都会自动带上「角色生图标签 + 质量标签 AQT」，无需每次手写

## 四、技术说明
- **形态**：SillyTavern 页面内扩展（`SillyTavern.getContext()` 桥接）+ 全屏 iframe 前端
- **前端**：原生 JS + 微信风格 CSS（无框架、无构建）
- **聊天**：走酒馆 `/api/backends/chat-completions/generate`（复用酒馆已配置的模型与 key）
- **生图**：直连 NovelAI `image.novelai.net`（与智绘机同机制，NAI4.5 payload 对齐智绘机：`skip_cfg_above_sigma=58`、不带 sm/sm_dyn、附 AQT 质量标签）
- **朋友圈**：酒馆群组会话，消息体用标记协议（动态 / 评论）
- **公众号**：酒馆另一个群组会话，消息体用标记协议（`【公众号文章】`），发布人 = AI 拟的公众号名；正文/封面等字段写入时经 URL 编码，可安全包含 `;` `=` 与 base64 图片
- **生图**：优先直连 NovelAI `image.novelai.net`（与智绘机同机制，NAI4.5 payload 对齐智绘机：`skip_cfg_above_sigma=58`、不带 sm/sm_dyn、附 AQT 质量标签）；直连网络失败自动回退酒馆 `/api/novelai/generate-image` 代理（代理路径同样兼容 NAI4.5）
- **转发卡片**：分享到私信时在消息 `extra.card` 里带卡片元数据（类型/标题/来源/缩略图），`mes` 里带完整"谁发的 + 内容"，渲染成微信式可点击卡片，点击跳回朋友圈原文 / 公众号阅读页
- **世界书挂载**：玩家账号存 `wbSel`（世界书 id → 启用的条目 uid），保存时拼接为注入文本
- **会话映射**：localStorage 键 `wx_sessions_v1` / `wx_current_v1`；历史会话按角色唯一标识分桶
- **多端同步**：白名单 / 账号 / 设置 / 悬浮窗位置都存在酒馆设置文件里，多台电脑同一酒馆数据即同步
- **账号备份**：扩展侧直接调酒馆 REST（`/characters/{avatar}` 取角色卡 png、`/api/worldinfo/get` 取世界书、`/api/chats/get` 取聊天），导入时经 `/api/characters/import`、`/api/worldinfo/import`、`/api/chats/save` 写回（multipart 文件字段名 `avatar`，对齐酒馆全局 multer）

## 五、已知边界
- ~~朋友圈/公众号标记按 `;` 与 `=` 解析，正文含 `;` 会截断~~ → 已修复：正文/封面/标题等字段写入时 URL 编码，可安全包含 `;` `=`（旧数据兼容）

## 六、技术依赖
- 依赖 SillyTavern 自带的 NovelAI 生图接口与 chat-completions 接口
