# 微信 · WeChat for SillyTavern（酒馆微信）

把 SillyTavern（酒馆）角色卡包装成一个**仿微信聊天前端**，并内置**朋友圈**模块。
运行在酒馆页面内（悬浮 💬 按钮打开），适配手机浏览器与桌面浏览器。

- 聊天模型 / 生图 / 通讯录白名单 / 朋友圈自动发布全部可在**设置面板**手动调节
- 数据存酒馆自己的角色卡、聊天文件与群组会话，**不需要额外后端**
- 通讯录**白名单**：只把你勾选的角色卡放进通讯录；也**只有白名单角色能发朋友圈**

---

## 一、功能总览

### 1. 聊天（仿微信）
| 模块 | 说明 |
|---|---|
| 通讯录 | 展示**白名单内**的角色卡（头像 + 名字），点击进入最近会话；右上角 ➕「新朋友」白名单流程，同意才加入 |
| 聊天页 | 顶部角色名（点按进详情）、绿/白气泡、多气泡拆分（`\|\|\|` 分隔标记）、自动滚底、表情面板、**每角色可自定义聊天背景（含本地上传图片）** |
| 角色详情 | **微信个人资料风**：大头像、备注/个性签名可改、简介可折叠、历史会话可折叠、**会话可直接删除**、多开场白自动拆成独立会话 |
| 多会话 | 酒馆原生一个角色一个会话，本项目用 localStorage 自建映射，同一角色可有多条会话存档 |

### 2. 朋友圈
- 用酒馆的一个**特殊群组会话**当存储：每条动态 = 群组里一条消息，评论 = 附加消息
- 时间线滑动浏览：封面、头像、正文、**配图**（AI 生图 / 本地上传）、评论区；最新在上
- **AI 自动发圈**：选择角色后，AI 结合**与该角色的最近聊天**自动写文案 + 自动写生图提示词 + 配图并发布；配图方式可选 **无图 / AI 生图 / 上传图片**
- **我发朋友圈**：发布弹层固定以「我」的账号发布，可一键 **✨ AI 生成草稿**（AI 参考你选的角色的聊天、以玩家本人人设写文案和提示词，可改后发）
- 评论：手动评论（角色或我）或 **AI 代写评论**（以该角色身份，自动贴合朋友圈内容）；发布后可自动让关联角色来点赞评论
- **删除**：每条动态右上角 `⋯` 删除（连带评论），每条评论旁 `✕` 删除单条（自定义微信风确认弹窗）

### 3. 「我」页 + 账号管理
- 多 Player 账号（存档在酒馆设置里，多端同步）：切换账号 = 换身份
- 每账号可设：头像（角色卡 / 酒馆用户设定 / 本地上传）、名字、微信号、个性签名、**人设描述**、朋友圈封面、**世界书/我的设定**（可从已导入世界书勾选条目载入）、**关联角色与关系**（如：五条悟=师生、备注、生图标签）
- 从酒馆「用户设定」一键导入账号（自动带上人设）
- AI 发朋友圈 / 评论 / 帮我发圈草稿时，都会带上**当前账号的人设 + 世界书 + 与角色的关系**

### 4. 设置面板（悬浮按钮 → ⚙️）
- **在酒馆「扩展程序」设置页也能开关**：酒馆设置 → 扩展程序，能看到「微信 · WeChat for SillyTavern」抽屉，含 **启用扩展** 和 **显示悬浮窗按钮** 两个开关
- **通讯录白名单**：全选 / 清空 / 反选；同名角色卡可分别勾选；支持「按酒馆 tag 自动加入通讯录」（如 tag `咒回单人` 的角色卡自动进通讯录）
- **聊天模型**：来源 / API 地址 / 模型 / 温度 / 最大 Token（**留空 = 用酒馆当前配置**）
- **生图（对齐智绘机）**：直连 NovelAI API（与智绘机同机制）、**一键从智绘机导入全部配置与预设**（模型/宽高/步数/采样器/调度器/API Key/**正负面提示词/质量标签 AQT/全部提示词预设**）；AI 发圈自动带上角色生图标签 + 质量标签，出图效果与智绘机一致
- **朋友圈**：AI 一键发圈是否直接发布、自动评论开关与数量

## 二、安装（在你的酒馆上装一次）

### 方式 A：酒馆扩展管理器（推荐，可自动更新）
1. 打开酒馆 → 右侧「扩展」菜单（拼图/扳手图标）
2. 切到「第三方扩展」→ 「安装扩展」，粘贴仓库地址：
   ```
   https://github.com/zzzu2221/SillyTavern-WeChat
   ```
3. 安装后启用 **「微信 · WeChat for SillyTavern」** 扩展。
4. 刷新酒馆页面，屏幕中央会出现绿色 **💬** 悬浮按钮（可长按拖到任意位置）。

### 方式 B：手动拷贝
把本仓库的 `manifest.json` + `extension/` + `app/` 整体复制到酒馆的
`SillyTavern\data\default-user\extensions\SillyTavern-WeChat\`（或全局
`public\scripts\extensions\third-party\SillyTavern-WeChat\`）下，然后在扩展列表里启用。

## 三、使用步骤

1. 点悬浮 **💬** 打开微信
2. 首次进入会自动创建一个「朋友圈」群组（酒馆里名为 `朋友圈`）
3. 「我」页 → 账号管理：确认/导入你的账号（人设/世界书/关联关系）
4. ⚙️ 打开设置：勾选要放进通讯录的角色卡，点保存
5. 通讯录选角色 → 开始聊天；朋友圈页右上角 📷 手动发布 / 🤖 AI 自动发圈

### 生图（NovelAI）配置
- **推荐**：设置面板 → 生图 →「↺ 从智绘机导入」一键带入智绘机全部参数与预设（若装了智绘机 st-chatu8）
- 未装智绘机：手填 API Key（酒馆密钥 `api_key_novel` 也可）、模型 `nai-diffusion-4-5-full`、尺寸、采样器等
- AI 发圈 / 手动生图都会自动带上「角色生图标签 + 质量标签 AQT」，无需每次手写

## 四、技术说明
- **形态**：SillyTavern 页面内扩展（`SillyTavern.getContext()` 桥接）+ 全屏 iframe 前端
- **前端**：原生 JS + 微信风格 CSS（无框架、无构建）
- **聊天**：走酒馆 `/api/backends/chat-completions/generate`（复用酒馆已配置的模型与 key）
- **生图**：直连 NovelAI `image.novelai.net`（与智绘机同机制，NAI4.5 payload 对齐智绘机：`skip_cfg_above_sigma=58`、不带 sm/sm_dyn、附 AQT 质量标签）
- **朋友圈**：酒馆群组会话，消息体用标记协议（动态 / 评论）
- **会话映射**：localStorage 键 `wx_sessions_v1` / `wx_current_v1`；历史会话按角色唯一标识分桶
- **多端同步**：白名单 / 账号 / 设置 / 悬浮窗位置都存在酒馆设置文件里，多台电脑同一酒馆数据即同步

## 五、已知边界
- 朋友圈标记按 `;` 与 `=` 解析：正文若含 `;` 或 `=` 会截断（建议正文避开这两种符号）
- AI 生图需要能访问 `image.novelai.net`（真实网络环境；代理模式下酒馆 node 端连不上时请把生图方式设为「直连」）
- 朋友圈配图以 data URL 存进群组消息，图大会让聊天文件偏大
- 若扩展在酒馆里一直不显示：到「扩展」菜单确认它没有被禁用，启用后刷新页面即可
